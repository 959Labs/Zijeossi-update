# ⚔️ 《지저씨 : 각성했지만 게으르고 싶어》 (Uncle Bob's Lazy Awakening)

## 🌟 주요 특징 (Key Features)

- 👑 **공식 영문 타이틀 & 글로벌 다국어(i18n) 시스템 (Uncle Bob's Lazy Awakening)**:
  - 메인 타이틀 화면 및 환경설정에서 원클릭으로 🇰🇷 한국어 ↔ 🇺🇸 English 실시간 언어 전환 지원
  - 15개 대륙, 40여 종 아이템, 32개 스킬/툴팁, 20개 챕터 퀘스트, NPC 대화문 100% 전면 영문화 완료
- 🌐 **4인 실시간 분산 코옵 멀티플레이 (Co-op Multiplayer)**:
  - 분산 구역 호스트(Distributed Zone Authority) 기반 렉 없는 실시간 4인 파티 사냥 & 보스 레이드
  - 4대 직업군 32종 스킬 이펙트, 투사체, 탄막, 외형 및 장비 100% 원격 실시간 동기화
  - 다중 플레이어 동적 어그로(Dynamic Aggro) 보스 AI 및 파티 협동 경험치/보상/퀘스트 분배
- 💬 **실시간 인게임 채팅 & 머리 위 네온 말풍선**: `[Enter]` 키로 채팅창 토글 및 4.5초 자동 페이드아웃 말풍선
- 👥 **몬스터헌터 스타일 파티원 HUD & 레이더 추적**: 직업 아이콘, 실시간 HP 바, 현재 위치한 맵 표시 및 원클릭 `[합류 🚀]` 순간이동
- 👑 **메인 타이틀 멀티플레이 전용 로비**: Wi-Fi 친구 초대 주소(`http://192.168.0.X:3000`) 원클릭 복사 및 `[~~_지저씨]` 센스 닉네임 생성기
- 🌟 **4대 직업군 전용 스킬 20종 대확장 & 2차 각성 궁극기**: 검사(천지개벽 참격폭풍), 궁수(유성우 폭격 화살비), 마법사(시공간 붕괴 블랙홀), 암살자(그림자 분신 환영살)
- ⚡ **2차 각성 패시브 시스템**: 검사(불굴의 투기), 궁수(방구석 매의 눈), 마법사(무한의 마력로), 암살자(치명적 암살 본능)
- 🗼 **무한의 시련 탑 (Tower of Trial)**: 1층부터 50층까지 몬스터 웨이브와 계단식 보스 아레나 돌파
- 🪙 **시련의 증표 & 전용 상점 (아스텔)**: 시련 돌파 증표로 직업별 최고위 전설 무기 및 초월 영약 교환
- 📡 **전술 레이더 미니맵 (`[Tab]` 키)**: 화면 중앙에 던전 지형, 몬스터, 보스, 포탈, 파티원을 투영하는 반투명 전술 오버레이
- 🛵 **배달앱 자동 물약 (Auto-Potion)**: 체력 임계치 설정 시 위기 상황에서 가방 물약 자동 결제 ("띵동! 배달 완료!")
- 🗺️ **24개 대륙 노드 원정 지도 (`[M]` 키)**: 메이플스토리 감성의 6x4 전 대륙 시각적 맵 & `마을 귀환 주문서`
- 🎲 **959 럭키 카지노 하우스**: 시작의 마을 도박사 잭과 즐기는 주사위 하이-로우 & 3-릴 슬롯머신
- 🔊 **100% 절차적 사운드트랙**: Web Audio API 기반 오케스트라 BGM & 959 Labs 시네마틱 스튜디오 팡파레
- ⚡ **100% 오프라인 싱글플레이 완벽 지원**: 인터넷 연결 없이도 싱글플레이 모드로 모든 컨텐츠 플레이 가능

## 🚀 빠른 시작 (Quick Start)

### 1. 멀티플레이 서버 실행 (호스트)
```bash
# 의존성 패키지 설치
npm install

# 멀티플레이 중계 서버 시작 (기본 포트: 3000)
npm start
```

### 2. 게임 접속
- **내 컴퓨터 (호스트)**: 웹 브라우저에서 `http://localhost:3000` 접속
- **친구 (같은 Wi-Fi / LAN)**: 웹 브라우저에서 `http://<호스트IP>:3000` 접속 (예: `http://192.168.0.2:3000`)
- **스마트폰**: 브라우저 접속 시 모바일 전용 가상 조이스틱 & 액션 패드 자동 활성화 📱

## 🎮 기본 조작키 가이드

| 분류 | 키보드 키 | 동작 설명 |
| :--- | :--- | :--- |
| **이동** | `W`, `A`, `S`, `D` 또는 `방향키` | 8방향 상하좌우 자유 이동 |
| **기본 공격** | `J` 또는 마우스 클릭 | 무기군별 고유 공격 (검: 3단 베기, 활: 원거리 사격, 지팡이: 3갈래 유도탄, 단검: 5연타 난무) |
| **파티 채팅** | `Enter` | 실시간 파티 채팅창 열기 / 전송 (닫기: `ESC`) |
| **회피 / 대시** | `Space` 또는 `방향키 더블탭` | 무적 판정 롤링 회피 기동 |
| **상호작용** | `F` | NPC 대화, 상점/대장간/카지노/시련상점 열기, 포탈 이동, 보물상자 열기 |
| **스킬 슬롯** | `Q`, `W`, `E`, `A`, `S`, `D`, `Z`, `X`, `C` | 장착된 9개 액티브/패시브 스킬 및 궁극기 즉시 시전 |
| **스킬북 메뉴** | `K` | 직업별 스킬 트리 관리 및 단축키 지정 |
| **전술 레이더** | `Tab` | 화면 중앙 반투명 레이더 미니맵 & 파티원 추적 토글 |
| **월드맵 (지도)**| `M` | 24개 대륙 노드 연결 원정 지도 열기 |
| **인벤토리** | `I` / `B` | 가방 열기, 직업 칭호 배지 확인, 아이템/장비 사용 및 장착 |
| **환경설정 / 일시정지** | `P` / `ESC` | 사운드, 자동 물약 설정, 세이브 백업 |
